# Writing skills

Generic writing workflows backed by an optional, replaceable profile.

## Start here

1. Install `setup-writing` and the writing skills you need.
2. Invoke `setup-writing` once per project to create `.writing/`.
3. Use `writing-write` as the usual front door, or invoke a specialist skill directly.

## Skills

| Skill | Job |
| --- | --- |
| `setup-writing` | Install or initialise the shared writing profile. |
| `writing-write` | Diagnose the material and choose the smallest useful workflow. |
| `writing-itch` | Find the worthwhile claim, question or decision. |
| `writing-interview` | Extract experience and original material from the author. |
| `writing-impact` | Strengthen purpose, evidence, consequence and memorability. |
| `writing-bullshit` | Attack vague, unsupported or generic reasoning. |
| `writing-elements` | Improve sentence-level clarity and economy. |
| `writing-voice` | Preserve or restore the active profile's voice. |
| `writing-learn` | Propose durable profile changes from explicit feedback. |

The skills work for blog posts, memos, strategy documents, design documents, proposals and internal writing. The active profile changes what good sounds like; the document's purpose changes what good structure looks like.

See [the profile contract](../../docs/PROFILE.md) and [example sessions](../../examples/writing/sessions.md).
