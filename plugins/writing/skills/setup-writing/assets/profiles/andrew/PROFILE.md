# Andrew McCall writing profile

This profile began with Andrew's technical blog writing but is intended to travel across formats: blog posts, memos, strategy documents, design documents, proposals and internal writing.

- Language: British English, except official names and established technical terms.
- Default audience: a smart technical or technical-adjacent reader.
- Core quality: an experienced engineer thinking through a concrete problem in public.
- Maintenance: change the guides only through explicit approval; record durable changes in `decisions/`.

Format-specific requirements supplied by a project or user, such as Jekyll front matter, company templates or proposal sections, supplement this profile rather than belonging in it.
