# Elements pass

Improve the prose without changing the author's meaning or identity.

Load `ELEMENTS.md` and `VOICE.md` from the user-named profile or the first available profile at `.writing/`, `.writing-profile/`, `~/.writing/` or `~/.codex/writing-profile/`. Continue with sound sentence-level judgement when no profile exists.

Voice outranks mechanical neatness. Never make a sentence technically cleaner when doing so makes it less recognisable or removes useful rhythm, context, uncertainty or humour.

## Review

Look for needless words, vague abstraction, weak nouns and verbs, habitual qualifiers, obscured actors, separated related ideas, duplicated explanations, awkward sentence structure and endings that continue after the point has landed.

Prefer active constructions when the actor matters, not as a universal rule. Preserve technical terms when they are precise. Preserve deliberate fragments, repetition, conversational openings and unusual rhythm when the profile supports them.

## Respond or edit

If the user asked for a review, show the few changes with the highest return and explain each briefly. If the user asked for an edit, revise the text and summarise the kinds of change made.

Do not silently alter facts, claims, quotations, numbers or the degree of certainty. Flag a reasoning problem for `writing-bullshit` rather than disguising it with polished prose.
